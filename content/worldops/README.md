# 澄空域：可审阅的首段互动内容

`lantern-message.source.json`把既有“星灯节前夜”的泛化参与选项细化为一次实际留言选择。三条留言分别产生明确的签名事实；延期和拒绝不完成任务，也不产生已完成共同经历。内容允许忽略，不惩罚用户。

此文件是内容源，不是已发布正典。它没有私钥、签名、伪造审批或自动激活代码。编译、lint及隔离的签名校验/参与/任务/记忆链路可以在明确QA场景验证；正式投放必须经真实内容审核、签名服务、发布及可信公钥配置。客户端不得自行冒充内容发布者。

现有运行栈的`local_split_development`包仍属于本机开发内容；客户端必须标明来源。正式远程内容服务及KMS/HSM部署属于独立交付，不能由一份本地测试签名代替。
